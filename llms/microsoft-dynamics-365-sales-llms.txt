## Calling the API

- Base URL is per environment: `https://{org}.api.crm.dynamics.com/api/data/v9.2`
- Every request: `Accept: application/json`, `OData-MaxVersion: 4.0`, `OData-Version: 4.0`, `If-None-Match: null`
- Auth: `Authorization: Bearer <Microsoft Entra ID token>`
- POST and PATCH return `204 No Content` by default; add `Prefer: return=representation` for a body
- Paging: `Prefer: odata.maxpagesize=<n>`, follow `@odata.nextLink`; 5,000 records max per page
- There is NO idempotency key. A retried POST creates a duplicate. Supply the GUID yourself and PATCH instead.
- Rate limits: 6,000 requests / 1,200s execution time per 300s sliding window, 52 concurrent — per user, per web server. On 429, honour `Retry-After`.
